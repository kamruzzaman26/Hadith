# Hadith Research Platform — Starter Demo

বাংলা ও আরবি হাদীস অনুসন্ধান ও গবেষণা প্ল্যাটফর্মের একটি স্ট্যাটিক, বিনামূল্যের প্রাথমিক ডেমো।

## ফিচার
- Responsive mobile/desktop layout
- আরবি ও বাংলা ডেমো টেক্সট সার্চ
- আরবি হরকত ও কিছু অক্ষর-রূপ normalize করা
- হাদীসের বিবরণ, উৎস ও যাচাই-অবস্থা
- রেফারেন্স কপি
- Print / Save as PDF
- GitHub Pages-এ প্রকাশের উপযোগী; কোনো build step দরকার নেই

## চালানোর পদ্ধতি
1. এই ফোল্ডারের সব ফাইল GitHub repository-তে upload করুন।
2. `index.html` খুলে ডেমো পরীক্ষা করুন, অথবা GitHub Pages চালু করুন।
3. GitHub repository → Settings → Pages → Build and deployment-এ `Deploy from a branch` বেছে `main` branch ও `/(root)` নির্বাচন করুন।
4. প্রকাশিত URL-এ পরীক্ষা করুন।

## গুরুত্বপূর্ণ সীমাবদ্ধতা
- এটি পূর্ণাঙ্গ হাদীস ডেটাবেস নয়।
- ডেমো ডেটা দিয়ে সার্চের আচরণ দেখানো হয়েছে।
- “উৎস সংযুক্ত” মানেই সম্পূর্ণ সনদ-তাহকীক সম্পন্ন—এমন নয়।
- কোনো ফলাফল না পাওয়া মানে হাদীসটি জাল নয়।
- AI grading, রাবি-সনদ বিশ্লেষণ, login, database বা private API এই সংস্করণে নেই।
- প্রকৃত ডেটা যোগ করার আগে উৎস, সংস্করণ, অনুবাদ, লাইসেন্স ও পুনঃপ্রকাশের অনুমতি যাচাই করুন।

## পরবর্তী ধাপ
1. অনুমোদিত ডেটা উৎস নির্ধারণ।
2. ডেটা schema ও import validation।
3. সার্ভার-সাইড API ও ডেটাবেস।
4. রাবি, সনদ ও একাধিক grading opinion-এর সম্পর্ক।
5. উৎস-সংযুক্ত AI research assistant।
6. গবেষক/বিশেষজ্ঞের human review ও audit log।
