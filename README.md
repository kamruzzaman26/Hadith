# Hadith Research Platform — Final Starter

বাংলা/আরবি ডেমো অনুসন্ধান, রেফারেন্স বিবরণ, চারটি গবেষণা-উৎস, বাংলা ব্যবহার নির্দেশিকা এবং সম্ভাব্য ডুপ্লিকেট সতর্কতা-সহ একটি static GitHub Pages প্রকল্প।

## আপলোড
1. ZIP extract করুন।
2. GitHub repository-তে `index.html`, `app.js`, `style.css`, `data/hadith-demo.json`, `README.md` ফাইল আপলোড করুন।
3. একই নামের পুরোনো ফাইলগুলো replace করুন; `data` ফোল্ডারের ভেতর JSON রাখুন।
4. Commit changes করুন এবং Pages আপডেট হওয়া পর্যন্ত অপেক্ষা করুন।

## সীমাবদ্ধতা
- ডেটা ছোট ডেমো, পূর্ণাঙ্গ হাদিস ডেটাবেস নয়।
- বাহ্যিক সাইটের ডেটাবেস/API এখানে সরাসরি সংযুক্ত নয়।
- সম্ভাব্য ডুপ্লিকেট শনাক্তকরণ কেবল একইরকম normalized text-এর উপর ভিত্তি করে; এটি একই সনদ বা একই হাদিসের প্রমাণ নয়।
- “উৎস সংযুক্ত” মানে লিংক আছে, স্বয়ংক্রিয় তাহকীক সম্পন্ন নয়।
- ডেটা বাড়ানোর আগে অনুবাদ, নম্বর, লাইসেন্স এবং ব্যবহারের অনুমতি যাচাই করুন।
