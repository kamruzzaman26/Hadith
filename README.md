# Free Hadith Research Guide

**হাদিস অনুসন্ধান, তাকরিজ ও তাহকিকের বিনামূল্যের বাংলা নির্দেশিকা।**

এই প্রজেক্টটি নির্ভরযোগ্য হাদিস গবেষণার ওয়েবসাইটগুলোর লিংক এক জায়গায় সাজিয়ে দেয় এবং প্রতিটি সাইটে হাদিস অনুসন্ধান, তাকরিজ ও তাহকিক করার সহজ বাংলা নির্দেশনা দেয়।

## বৈশিষ্ট্য

- সম্পূর্ণ বিনামূল্যে ও ওপেন-সোর্স
- HTML, CSS ও JavaScript দিয়ে তৈরি
- কোনো API, API key, ব্যাকএন্ড, ডাটাবেস বা সাবস্ক্রিপশন লাগে না
- মোবাইল, ট্যাবলেট ও কম্পিউটারে ব্যবহারযোগ্য
- বাংলা-প্রধান ইন্টারফেস; আরবি লেখার RTL সমর্থন
- নিজস্ব নির্দেশিকার মধ্যে সার্চ ও বিষয়ভিত্তিক ফিল্টার
- হাদিস যাচাইয়ের ৮টি ধাপ
- আরবি হাদিস-পরিভাষার বাংলা ব্যাখ্যা

## কীভাবে ব্যবহার করবেন

1. এই repository থেকে `index.html` ফাইলটি ডাউনলোড করুন।
2. ফাইলটি যেকোনো আধুনিক ব্রাউজারে খুলুন।
3. সার্চ বক্সে `Dorar`, `তাকরিজ`, `বাংলা অনুবাদ`, `সনদ` ইত্যাদি লিখে নির্দেশিকা খুঁজুন।
4. যে ওয়েবসাইটে যেতে চান, সেই কার্ডে **“ওয়েবসাইট খুলুন”** চাপুন।
5. **“বাংলা নির্দেশিকা দেখুন”** চেপে ধাপে ধাপে নির্দেশনা পড়ুন।
